## Second verification pass: corrections and unresolved differences

This pass compared the current operator release, older client releases, the MPA overview and detailed paper against the proposed assertions. It is a separate pass by the same assistant, not an independent expert audit.

| Potential misleading claim | Re-check result / presentation rule |
| --- | --- |
| One “completion” date | Reclamation completion, first operations and ceremonial opening refer to different events. Preserve all three. |
| All published berth targets agree | They do not; see `tuas-berth-target`. Prefer dated current operator status; show target discrepancy without inventing a resolution. |
| Phase 2 wharf and seawall lengths are interchangeable | Different terms/values remain unresolved; see `tuas-phase2-length`. Avoid using either to generate exact geometry. |
| Article timestamp means all content is current | MPA overview still contains forward-looking 2022 language. Use dated passages; site-footer update dates are not fact dates. |
| Port capacity equals annual throughput | Capacity is a future design target. A cumulative throughput milestone is neither current capacity nor annual throughput. |
| Newly reclaimed area equals total improved platform | Distinguish the scopes; see `tuas-area`. The project paper also describes a broader approximate area. |
| Five metres MSL conflicts with +6 m CD | They use different datums. No conversion verified; do not subtract or combine them. |
| “40 mm over 60 years” is a universal operating limit | It is a reported project design requirement in the paper, not a universal berth or AGV tolerance. Leave it in technical evidence notes. |
| A caisson sits directly on arbitrary soft seabed | Source methods include foundation preparation and local ground replacement. Show material interfaces, not a floating box on mud. |
| Every caisson cell/rebar detail is documented | Outer scale is supported; internal model remains schematic. |
| All fill is clean imported sand | Reuse is central to the story. Exact material fractions/profile vary; do not colour the entire section as sand. |
| Two MPA pages are independent corroboration | Same-origin corroboration only. The technical paper adds project-team detail, not independent certification. |
| Coral relocation proves no environmental loss | No survival or whole-ecosystem outcome is established here. Explain mitigation without such a claim. |
| NLB's old forecast is current | Exclude its obsolete completion forecast; historical regional context only. |
| Future completion is exactly 2050 | 2050 is a viewing horizon; the programme completion target is separately sourced. |

## Remaining gaps and approved-package exclusions

There is no verified comprehensive phase GIS, contract-level construction programme, exact caisson reinforcement/ballasting plan, vessel specification, full operational commissioning checklist, maintenance schedule, actual AGV control software or independently validated environmental outcome in this package. These gaps are bounded: illustrate only supported relationships; omit numeric claims and exact layouts that would depend on the missing evidence. Discovering evidence that materially changes the proposed model requires a revised Gate A baseline.

## Rights and attribution

MPA's [terms](https://www.mpa.gov.sg/footer/terms-of-use) reserve rights in its material; do not treat public availability as asset redistribution permission. PSA's [terms](https://www.singaporepsa.com/term-of-use/) and copyright notice likewise do not provide a blanket asset licence. Record sources and original factual synthesis; no photos, maps, technical figures, models or logos are imported into the app. Rights status for any future imported asset is a separate check.
