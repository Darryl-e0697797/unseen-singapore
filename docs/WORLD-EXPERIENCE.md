# Engineering world — geographic surface milestone

The portfolio entrance remains at /. The product lives at /explore: a full-viewport, perspective 3D environment with national orientation, selectable engineering destinations and component-scale inspection. These are three different scales, not one city mesh.

Nine initial destinations cover the original themes and add utilities/underground structures: DTSS, MRT construction, Tuas Port, NEWater, Marina Barrage, reclamation/polders, coastal resilience/Long Island, Jurong Rock Caverns and power cable tunnels. Each has an overview, origin/rationale, technology, construction work packages, trade-offs and a five-period timeline.

The default surface uses the documented live OneMap raster basemap in Web Mercator, rendered with MapLibre. Streets, water and labels are provider cartography. An attributed 1,865-footprint CBD extract from OpenStreetMap adds extruded building context. It has partial coverage and mixed height quality; clicking a building identifies its height basis. The earlier Natural Earth geometry remains a legacy orientation asset, not the default surface. Markers are deliberately approximate thematic locations and are not asset survey points. Explorable detailed models are standalone, originally authored schematic exhibits with exaggerated scale. Do not draw precise underground routes across the country. No walkable interior is represented as a surveyed facility.

Interaction hierarchy: pan/zoom Singapore or switch 2D/3D → select a destination and fly to its map context → enter its engineering exhibit → orbit or enter inspect/flight navigation → scrub construction stages/explode components → open the full sourced story → return to country. Persistent accuracy and temporal labels apply to all modes. Nine stories remain discoverable at every date, but unavailable/pre-project geometry is not rendered as built. 2050 is a planning lens, not a common promised completion date.

World controller accepts only validated destination IDs, registered view modes, bounded stage indexes and the five covered snapshot years. Typed authored questions may select a project or a chapter; they cannot create geometry or run code. Existing DTSS proof remains a separate chapter.

Performance: generated exhibit GLBs under 2 MiB each; load active detailed exhibit only. The MapLibre surface uses a bounded raster tile cache and a 817,736-byte local GeoJSON layer. The Three.js exhibit mounts only after story entry; returning preserves map position. The module worker and matching shared module are copied from the installed MapLibre package before development/build. Camera transitions use frame-time interpolation, reduce-motion snaps; flight navigation requires explicit activation, ignores form input and exits with Escape. Pointer lock is not required. Mobile uses orbit and screen buttons. Every 3D selection also has an HTML equivalent.

This milestone provides breadth and researched story structure. High-fidelity site reconstructions, full facility interiors, validated engineering models, exhaustive contract archives and a live-model service remain additional work. Do not describe these as complete based on a national overview.
