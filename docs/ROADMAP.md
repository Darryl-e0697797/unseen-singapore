# Roadmap and exit gates

## 0 — Architecture and contracts
Machine inventory, repository, all foundation docs, schemas, source registry and test harness. Exit: reviewed coordinate conventions and executable validation. No bulk city generation.

## 1 — Asset pipeline proof
Headless Blender generates one representative cutaway asset and LOD; validate GLB orientation and manifest; load, select and orbit in browser. Exit: screenshot, console check, mesh visible, click updates HTML description. Commit proof before national content.

## 2 — First DTSS vertical slice
Singapore orientation plus architectural context, reveal, independently visible DTSS/MRT, flow trace, curated Ask Singapore, four narrative depths and source drawer. Exit: browser tested desktop/mobile, schema/unit tests, lint/type/build, honest geometry and authored-guide labelling. Initial scope is educational schematic, no geospatial twin or live model claim.

## 3 — Licensed Singapore base and production hardening
Acquire rights-cleared country/district context. GIS adapters, tiled local origins, spatial LOD, performance measurement on ordinary hardware. Add CI, source refresh/review workflow and live-model adapter only after claim-level grounding tests. Exit: licensing and independent fact review, accessibility and mobile device gates.

## 4 — Tuas construction story
Research MPA public engineering descriptions and terms. Build documented stage ledger with representative caisson/reclamation animation. Distinguish constructed, operating, planned and complete-future states. Exit: sequence controls, evidence per stage, scale annotations grounded individually, no misleading simulation language.

## 5 — Time transformation
One licensed historical/modern viewpoint pair, explicit uncertainty and same-camera transition. Then independent 2050 alternatives with scenario metadata. Exit: no invented historical footprint; future assets cannot leak into present.

## 6 — National expansion and release
Water, rail, reclamation and coastal systems as separately loaded stories. Search, accessible alternatives, multilingual strategy, editorial CMS only when justified. User-led hosting on ChatGPT Sites after release gate; optional Unreal cinematics independent from web.

A working local first slice is not a completed national experience. Each phase preserves a runnable product. Later phases need new evidence rather than extrapolation from the starter model.
