# Contributing

Keep engineering claims tied to the source ledger and distinguish documented, reconstructed, schematic and envisioned content. Read AGENTS.md and the engineering build standard before changing detailed exhibits. Product acceptance is not proof of surveyed accuracy.

Run the README checks. Preserve all nine demos, keyboard access, reduced motion, source links and back/reset navigation. Include the source passage and phase/date applicability when proposing a factual correction. Do not contribute agency imagery or dataset extracts without identifying their reuse terms.

Avoid committing credentials, downloaded map tiles, generated build directories or private user prompts. Submit a focused pull request with the behaviour changed, evidence and validation results. Do not represent a new or simplified exhibit as accepted detailed work.
